# かなめ自動車整備（架空の整備工場）— ホームページの見本

NEXTRAY合同会社 が作った、町の車の整備工場のホームページの見本です（noindex）。お店・人物・数字は架空、写真は AI で作りました。

- 考え：「直す前に、ちゃんと見せる。」点検の結果を赤・黄・緑の札で見せる、車検の目安を国に納めるお金と当店の料金に分けて出す。
- 見た目：墨 #121518 と 紙 #efece6 の2色、差し色は安全黄 #f2a900。赤・黄・緑は札だけ。字は Zen Kaku Gothic New・Barlow Condensed・JetBrains Mono（Google Fonts）。
- ファイル：`index.html`／`assets/site.css`／`assets/site.js`／`assets/img/`（WebP）。
- 車検の目安の数字は見本（`assets/site.js` の F）。実際のお店に合わせて入れ替える。
